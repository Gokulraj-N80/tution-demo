# Demo Tuition Centre - Web Application

A responsive, modern web application for **Demo Tuition Centre**, built using React, Vite, Lucide Icons, and Vanilla CSS with full bilingual support (Tamil & English) and theme switching.

## ✨ Features

- **Bilingual Interface**: Seamless switching between Tamil (`ta`) and English (`en`).
- **Modern Institutional UI**: Responsive design with rich animations, hero badges, bento grids, and interactive feature cards.
- **Theme Switcher**: Switch between Royal Navy & Emerald and Midnight Forest & Mint themes.
- **Course Roadmap & Finder**: Interactive class and subject finder with syllabus roadmaps.
- **Admission Enquiry & Contact Forms**: WhatsApp and email integrations with auto-formatted messages.
- **Fast Build**: Built on Vite with quick reload and optimized production bundles.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
